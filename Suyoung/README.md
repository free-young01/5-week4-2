# KATO 동호인 테니스 대회 일정 챗봇

웹에서 실제 대회 일정을 수집하고, 일정을 임베딩해 Chroma에 저장한 뒤 자연어 질문에 답하는 과제입니다. 자료 출처는 [KATO 공식 홈페이지](https://kato.kr/)의 공개 대회 페이지입니다. 현재 범위는 KATO 홈페이지에 표시된 경기 중·접수 중·접수 예정 대회이며, 다른 단체의 전체 국내 대회를 포괄하지는 않습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `crawl_tournaments.py` | 홈페이지와 각 대회 상세 페이지의 부서별 날짜·장소·접수 상태 수집 |
| `data/kato_tournaments.json` | 수집 결과, 수집 시각, 원문 URL, 수집 오류 기록 |
| `tennis_chatbot.py` | OpenAI 임베딩 → Chroma 저장 → 날짜 필터와 벡터 검색 → 근거 기반 답변 |
| `FAQ.md` | 수집 원문과 대조해 직접 작성한 질문·답변 예시 |

## 실행

이 폴더에서 다음 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python crawl_tournaments.py
python tennis_chatbot.py index
python tennis_chatbot.py
```

`python tennis_chatbot.py`를 실행하면 `질문>` 입력창이 계속 나타납니다. 답을 받은 뒤 바로 다음 질문을 입력할 수 있고, `그 대회는?`처럼 직전 대회를 가리키는 질문도 할 수 있습니다. `quit`, `exit`, `종료` 또는 Ctrl+C로 끝냅니다. 한 번만 물어보려면 `python tennis_chatbot.py ask "질문"`도 사용할 수 있습니다.

`index`와 챗봇에는 OpenAI API 키가 필요합니다. 상위 `5-week4-2/.env`의 `OPENAI_API_KEY` 환경 변수를 읽으며, 키를 결과 파일이나 Git에 기록하지 않습니다. 크롤링은 API 키 없이 실행할 수 있습니다.

## 작동 방식과 확인할 점

1. KATO 홈의 대회 카드에서 공식 상세 페이지 링크를 찾습니다.
2. 상세 페이지에서 부서별 경기 일시와 장소를 추출해 JSON에 보존합니다.
3. 각 부서 일정을 하나의 문서로 만들고 임베딩하여 Chroma에 저장합니다.
4. 질문의 `이번 주말`, `다음 주말`, `이번 달`, `다음 달`, `11월`, `10월 25일` 같은 날짜 표현을 먼저 적용한 뒤 벡터 검색합니다.
5. 검색된 항목만 답변 모델에 전달하고 공식 링크를 답변에 포함하도록 요청합니다.

일정은 수집 시점의 스냅샷입니다. 일정 변경이나 접수 상태는 공식 페이지에서 확인해야 합니다. 일부 접수 예정 대회는 부서별 접수 표가 없어 `registration_status`가 `미기재`이며, 홈페이지의 대회 분류만 별도로 보존합니다. 새 일정을 반영하려면 수집과 인덱싱을 다시 실행하세요.

`data/chroma_db/`는 다시 만들 수 있는 검색 인덱스라 Git에서 제외했습니다.
